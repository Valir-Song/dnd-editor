# D&D Card Editor — приложение

Здесь лежит только готовый редактор листов D&D 5e для GitHub Pages. Исходный код находится в закрытом репозитории.

- Основная версия: https://valir-song.github.io/dnd-editor/
- Бета (свои сохранения, значок с β): https://valir-song.github.io/dnd-editor/beta/

Открой ссылку в Chrome или Edge и нажми «Установить», чтобы получить значок на рабочем столе.
Редактор работает без интернета, а макеты хранятся только на твоём компьютере.
Файлы здесь выкладываются автоматически, руками их не править.
